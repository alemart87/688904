# Propuesta de gestión de redes sociales · Tamara Raimondo

Propuesta comercial de Market Labs, diseñada en dos páginas A4.

## Archivos

- `propuesta-tamara.html`: la propuesta maquetada (fuente de verdad, editable).
- `propuesta-tamara.pdf`: exportación lista para enviar.
- `fonts/Montserrat-Variable.woff2`: tipografía incluida localmente para que el PDF salga igual sin conexión.

## Colocar el logo

Guardá el logo como `logo-marketlabs.png` en esta misma carpeta (fondo transparente, idealmente).
El HTML lo toma automáticamente en el encabezado de ambas páginas; si el archivo no existe,
se muestra el nombre "MARKET LABS" en texto como respaldo.

## Exportar a PDF

Abrí `propuesta-tamara.html` en Chrome o Edge y usá **Imprimir → Guardar como PDF** con:

- Tamaño: A4
- Márgenes: Ninguno
- Gráficos de fondo: activado

El paginado ya está definido en el archivo: la primera página contiene objetivo y servicios;
la segunda, inversión, presupuesto publicitario, forma de trabajo y alcance.
